# AI vs ML vs Deep Learning

## Overview
This project explains the differences between Artificial Intelligence (AI), Machine Learning (ML), and Deep Learning (DL).

## Objective
- Understand AI, ML, and Deep Learning.
- Compare their definitions and applications.
- Explore real-world examples.
- Understand their relationship.

## Comparison

| Feature | AI | ML | Deep Learning |
|---|---|---|---|
| Definition | Machines performing intelligent tasks | Computers learning from data | Learning using deep neural networks |
| Scope | Broadest field | Subset of AI | Subset of ML |
| Example | Virtual assistants | Spam detection | Face recognition |

## Real-World Applications
- **AI:** Virtual assistants and robotics.
- **ML:** Email spam detection and recommendation systems.
- **Deep Learning:** Image recognition and speech recognition.

## Relationship
Deep Learning is a subset of Machine Learning, and Machine Learning is a subset of Artificial Intelligence.

**AI → ML → Deep Learning**

## Tools Used
- Python
- Google Colab
- GitHub

## Conclusion
AI, ML, and Deep Learning are related technologies that help computers perform intelligent tasks, learn from data, and recognize complex patterns.
